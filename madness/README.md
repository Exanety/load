# Madness

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Exanety/load/main/madness/loader.lua"))()
```

Enter the Madness access key when prompted. Insert toggles the menu.
Accepted authentication requests log Madness, your Roblox username, user ID,
place and execution time through the validation service.

This release includes the UI and needs no additional executable dependencies.
Its generated payload uses local-variable renaming, minification and encoding.
Obfuscation makes casual inspection harder; client code can still be recovered
while it runs. Third-party license notices are included in the payload and
THIRD_PARTY_NOTICES.md.
